# Assets

Every asset in the game, where it came from and its licence. The game may be public, so nothing
here is ripped from a commercial game. Nothing is downloaded at runtime except the two Google
Fonts below.

## Art made for this project (code-generated)

| Asset | Files | Source | Licence |
| --- | --- | --- | --- |
| Room paintings: Hall, Attic, Crypt, Swamp, Chapel | `public/rooms/<room>/albedo.jpg` | Painted in code by `tools/paint_rooms.py` (procedural materials on a ray-cast perspective set) | Made by the team for this project; same licence as the code |
| Normal maps | `public/rooms/<room>/normal.jpg` | Derived by `tools/paint_rooms.py` from the scene geometry and material height fields | Same as above |
| Depth + gloss maps | `public/rooms/<room>/data.png` (R = nearness, G = gloss) | Written by `tools/paint_rooms.py` from the ray-cast depth | Same as above |
| Foreground parallax layers | `public/rooms/<room>/fg.png` | Drawn by `tools/paint_rooms.py` (cobwebs, chair back, reeds, pew end…) | Same as above |
| Item surfaces, doors, candles | `public/rooms/rooms.json` | Written by `tools/paint_rooms.py` alongside the paintings | Same as above |
| 12 costume silhouettes, pumpkins, hammer, souls, ghosts | `public/common.js` | Drawn in code at runtime (SVG paths / Canvas 2D) | Same as above |
| House facade, mantel, candle timer, floor plan | `public/host.js` | Drawn in code at runtime | Same as above |
| QR code | `/qr.svg` | Generated at runtime by the `qrcode` npm package (MIT) | MIT (library); the output is ours |
| All sound | `public/common.js` | Synthesised at runtime with the Web Audio API (no audio files) | Same as above |

Regenerate the rooms with `python3 tools/paint_rooms.py` (needs numpy and Pillow; add
`--preview DIR` for torch-lit previews). It is deterministic, so the same code gives the same rooms.

## Swapping in painted rooms

The renderer only needs the four files per room. Assets you can drop in instead:

* **Paintings generated by the team** (e.g. Gemini image generation) at 1920×1080, in the same
  fixed camera as the current room so `rooms.json` still lines up (or update its surfaces/doors).
* **Normal and depth maps** generated from those paintings, e.g. with
  [Laigter](https://azagaya.itch.io/laigter) (free, GPL tool; its output is yours) or a depth-estimation model.
  Normal map convention: view space, x right, y down, z toward the viewer, `rgb = n * 0.5 + 0.5`.
  `data.png`: red channel = nearness (255 nearest), green = gloss.
* **CC0 textures**, e.g. [Poly Haven](https://polyhaven.com) or [Kenney](https://kenney.nl), and
  CC0 sounds from [Freesound](https://freesound.org) (filter by licence: Creative Commons 0).

Add a row to the table above for every file you add.
